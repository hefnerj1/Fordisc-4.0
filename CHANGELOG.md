# Public Release Notes

This changelog summarizes public, user-facing changes. Internal development history, source changes, validation fixtures, and deployment details remain in the private FORDISC application repository.

## 4.0.2 — Subscription provisioning and contributor acknowledgments

- Improved recognition of manual TouchNet-to-Clerk subscription tier values for Student, Pro, and Institution accounts.
- Added clearer account eligibility, expiration, scope, and provisioning diagnostics.
- Published the approved current contributor roster in its required order.
- Preserved all accepted analytical, reference-data, report, graph, case, map, and anonymous-Free behavior.

## 4.0.1 — Map and report presentation

- Refined the Howells Reference Group Map and responsive presentation.
- Simplified user-facing product identity to **FORDISC 4.0**.
- Removed the internal R-engine identifier from practitioner-facing analysis reports.
- Preserved all accepted analytical behavior.

## FORDISC 4.0 — Initial web release

- Rebuilt FORDISC as a web application.
- Introduced a case-based workflow for FDB, Howells, and Postcranial data.
- Added modern Results, Extended Results, Graphs, reports, and Run Log workflows.
- Added anonymous Module Test Cases through FORDISC Free.
- Added Student, Pro, and Institution access models.
- Added stature display in inches or centimeters.
- Added a Howells Reference Group Map.
- Extensively compared supported analytical workflows with FORDISC 3 during beta validation.
