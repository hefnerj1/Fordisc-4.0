# Security and Sensitive Information

## Report security concerns privately

Do not disclose a suspected vulnerability in a public GitHub issue, discussion, pull request, or commit.

Send security concerns privately to **fordisc.support@gmail.com** with the subject line `FORDISC security report`.

## Do not post case information

Never include any of the following in this public repository:

- Case identifiers or case notes
- Measurements or analysis inputs
- Reports, Run Logs, screenshots, or exports containing case information
- Usernames, passwords, Clerk identifiers, session tokens, API keys, or TouchNet references
- Private FORDISC source code, computational-engine code, reference datasets, or deployment configuration

## Repository scope

This repository is for public project information and release notes only. The production application and private development repository are maintained separately.
