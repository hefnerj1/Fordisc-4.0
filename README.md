## What is new in FORDISC 4.0

FORDISC 4.0 rebuilds the FORDISC analytical workflow as a modern web application. Major additions include:

- Browser-based access with no local installation.
- Modern Results, Extended Results, graphs, reports, and a case-based Run Log.
- Anonymous FORDISC Free Module Test Cases.
- Student, Pro, and Institution access plans.

## Access

- **FORDISC Free:** Built-in FDB, Howells, and Postcranial Module Test Cases with Results and Graphs. No sign-in required.
- **FORDISC Student:** FDB and Postcranial access for eligible users, including measurement entry, Results, Graphs, and limited case management.
- **FORDISC Pro:** Full individual access to every currently supported FORDISC 4.0 module and tool.
- **FORDISC Institution:** Full access for organizations and laboratories, including 10 named users. Additional users may be added.

Current pricing and purchase options are maintained in the [UTK FORDISC Store](https://secure.touchnet.com/C21610_ustores/web/store_main.jsp?STOREID=15&SINGLESTORE=true). Account activation instructions are supplied by email after purchase; please allow up to 24 hours for setup.
