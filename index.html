Web-based forensic discriminant functions

FORDISC 4.0

FORDISC 4.0 is the modern web application for flexible cranial and postcranial analysis, including population-affinity, sex, and stature workflows built upon the FORDISC scientific tradition.

Current public release: 4.0.14
International Crania included

Public information repository. This repository contains project information and public release notes only. It does not contain the FORDISC application source, computational engine, reference datasets, case data, credentials, deployment configuration, or release binaries.

What's new

FORDISC rebuilt for the web

FORDISC 4.0 retains the analytical purpose of earlier versions while providing a modern, case-based web workflow.

Web application

No local installation

Access FORDISC through a supported web browser with production authentication and subscription controls.

Case workflow

Cranial and postcranial data together

One saved case can retain independent FDB, Howells, International Crania, Postcranial DFA, and Stature analysis state.

Analytical tools

Validated FORDISC workflows

Supported no-Stepwise and Stepwise workflows were extensively compared with FORDISC 3 during beta validation.

International Crania

Expanded cranial reference option

Run the independent International reference dataset through Fordisc Pro or Fordisc Institution access. It is not part of Student or Demo access.

Results

Modern tables, graphs, and reports

Review Results, Extended Results, accessible graphics, a five-lane Case Report, and the complete case-based Run Log.

Try before subscribing

Fordisc Demo

Run locked FDB, Howells, and Postcranial Demo Cases without signing in.

Access

Choose the appropriate FORDISC plan

Current pricing and purchase options are maintained in the University of Tennessee's secure storefront.

Fordisc Demo

Built-in FDB, Howells, and Postcranial Demo Cases with Results and Graphs. No sign-in, measurement entry, or case storage.

Available immediately. International Crania is not included.

Fordisc Student

FDB and Postcranial access for eligible users, including measurement entry, Results, Graphs, and limited case management.

A verified .edu address is accepted automatically. Other institutional domains, including international academic domains, require approval before purchase.

Fordisc Pro

Full individual access to every currently supported FORDISC 4.0 module and tool, including International Crania.

Individual named-user access.

Fordisc Institution

Full access for organizations and laboratories, including 15 named users. Additional named users may be added through an approved arrangement.

Includes International Crania.

Public release notes

Recent FORDISC 4.0 updates

Public release notes summarize user-facing changes. Internal development history remains in the private application repository.

Current public release

Release 4.0.14

  • Automatically accepts verified .edu addresses for Fordisc Student.
  • Supports approved exact institutional domains, including international academic domains.
  • Adds the reviewed Forensic Data Bank contributor and graduate research assistant acknowledgments.
  • Preserves all locked 4.0.13 analytical and display behavior.
Presentation and parity

Release 4.0.13

  • Standardized two-group DFA and multigroup CVA terminology and limited DF Weights to two-group analyses.
  • Added Standard, Soft Midnight, and Color-Vision Accessible viewing modes.
  • Refined reference-data advisories, measurement mouseovers, branding, and account-email workflows.
International Crania

Release 4.0.12

  • Added International Crania for Pro and Institution access.
  • Added independent saved-case state and a fifth Case Report lane.
  • Improved graph colors, labels, and layout across live and report graphics.

Forensic Data Bank acknowledgments

The Forensic Data Bank was built over several decades through contributions from investigators, laboratories, and graduate research assistants. Attribution in the legacy records is not uniform. Depending on the record, the named responsible party may be the laboratory director, submitting investigator, analyst, data collector, or person who digitized the data.
