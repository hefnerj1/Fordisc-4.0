# Citing FORDISC 4.0

The preferred FORDISC 4.0 citation is:

> Hefner, JT, Jantz RL, and Ousley SD. FORDISC 4.0: Personal computer forensic discriminant functions. University of Tennessee; 2026.

Analytical documentation should also record the FORDISC module, reference data, measurements, reference groups, and analysis options used.

When discussing the historical development of the methods, the FORDISC 3 citation remains relevant:

> Jantz, R. L., and Ousley, S. D. FORDISC 3: Computerized Forensic Discriminant Functions. Version 3.1. The University of Tennessee, Knoxville.
